Features

  • Supports WAV, AIFF, FLAC, OGG and many more
  • MP3 and video file import via FFMPEG
  • Real-time effects rack with mixer
  • Volume envelope automation
  • Built-in file manager with bookmarks
  • Session management
  • Customizable themes and hotkeys
  • Lightweight — no disk caching, all in memory
  • Rich set of tools for audio slicing, editing, and channel handling
